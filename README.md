# Sistema de Controle de Estoque

Sistema web desenvolvido como projeto acadêmico para gerenciamento e rastreabilidade de estoque.

## Sobre o projeto

O sistema tem como objetivo controlar produtos e suas movimentações, permitindo registrar entradas, saídas, usuários e outras operações relacionadas ao estoque.

## Funcionalidades

* Login de usuários
* Controle de permissões
* Cadastro de usuários
* Cadastro de produtos
* Entrada de materiais
* Saída de materiais
* Histórico de movimentações
* Controle de estoque
* Dashboard
* Relatórios

## Tecnologias utilizadas
